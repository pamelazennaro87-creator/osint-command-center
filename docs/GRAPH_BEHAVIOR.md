# Graph interaction semantics

The Living Graph is an investigative visualization, not a truth engine.

- **Supported** relationships are explicitly backed by recorded evidence.
- **Inferred** relationships are analytical links and must remain visually distinct.
- **Unsupported** relationships are unknown/unverified and must never be presented as facts.
- Selecting a node focuses its immediate context and dims unrelated graph elements.
- Edge hover exposes relationship context without changing analytical state.
- Keyboard activation mirrors pointer selection where the rendered node is keyboard-addressable.

The UI must not create, mutate, or silently promote evidence, entities, hypotheses, or decisions.
