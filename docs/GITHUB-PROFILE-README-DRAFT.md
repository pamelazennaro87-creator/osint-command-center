## How I work

**Question → Claims → Sources → Verification → Corroboration → Contradictions → Analysis → Confidence → Limitations**

I distinguish:
- directly observed evidence;
- claims made by a named source;
- independent corroboration;
- analyst inference;
- unresolved or contradicted hypotheses.

I look for evidence that could disprove a hypothesis, not only evidence that supports it. A repeated claim is not automatically an independent confirmation, and an indicator match is not attribution by itself.

## Research principles

- **Evidence before narrative.**
- **No invented access.**
- **No claims stronger than their evidence.**
- **Preserve uncertainty and false-positive explanations.**
- **Minimize unnecessary exposure of personal or sensitive data.**
- **Make conclusions reproducible and open to correction.**

AI can accelerate discovery, translation, classification, and synthesis. It is not a substitute for inspecting and verifying the underlying source.
